# IMU 与足底压力 CAN 通信协议

## 1. 总线配置

| 项目 | 配置 |
| --- | --- |
| 总线 | FDCAN1 |
| 帧格式 | Classic CAN，11 位标准 ID |
| 波特率 | 1 Mbit/s |
| STM32 发送 ID | `0x621` |
| STM32 接收 ID | `0x620`，当前未注册控制命令 |
| 遥测调度频率 | 200 Hz |

当前固件只发送 IMU 和足底压力数据，不发送电机反馈、目标位置、力矩、AO 参数或电机使能状态。

## 2. 应用层帧

每条完整消息按以下格式序列化：

| 偏移 | 大小 | 内容 |
| ---: | ---: | --- |
| 0 | 1 | 帧头 `0xEB` |
| 1 | 1 | 帧头 `0x90` |
| 2 | 1 | 消息 ID |
| 3 | 1 | 载荷长度 N |
| 4 | N | 消息载荷 |
| 4+N | 2 | CRC16，小端序 |

CRC 使用 CRC16-CCITT：初值 `0xFFFF`，多项式 `0x1021`，校验范围为 4 字节头部和全部载荷。CRC 低字节先发送。

## 3. 传感器消息 `0x05`

载荷采用紧凑结构体，无填充，共 196 字节。STM32H7 使用小端序和 IEEE 754 单精度浮点数。

| 顺序 | 字段 | 类型 | 数量 | 单位 |
| ---: | --- | --- | ---: | --- |
| 1 | 时间戳 | `uint32_t` | 1 | ms |
| 2 | IMU1 加速度 | `float` | 3 | g |
| 3 | IMU1 角速度 | `float` | 3 | deg/s |
| 4 | IMU1 欧拉角 | `float` | 3 | deg |
| 5 | IMU1 四元数 | `float` | 4 | W/X/Y/Z |
| 6 | IMU2 加速度 | `float` | 3 | g |
| 7 | IMU2 角速度 | `float` | 3 | deg/s |
| 8 | IMU2 欧拉角 | `float` | 3 | deg |
| 9 | IMU2 四元数 | `float` | 4 | W/X/Y/Z |
| 10 | 左、右步态相位 | `uint8_t` | 2 | 枚举值 |
| 11 | 左、右有效压力点数 | `uint8_t` | 2 | 个 |
| 12 | 左、右总压力 | `uint16_t` | 2 | 原始值之和 |
| 13 | 左足压力数组 | `uint16_t` | 20 | 原始值 |
| 14 | 右足压力数组 | `uint16_t` | 20 | 原始值 |

未连接或超过 500 ms 没有收到帧的 IMU 对应字段保持为零。若该路 IMU
仍有其他测量帧，但四元数在 500 ms 内没有更新，则仅四元数字段置零。
未连接的鞋垫对应字段保持为零。协议中没有逐路采样计数器或字段有效位，
持续收到整包并不能证明每个字段都持续刷新。

## 4. CAN 分片

一条消息总长度为 `4 + 196 + 2 = 202` 字节，因此每个样本占用 26 个经典 CAN 帧。第一个 CAN 帧为：

以 200 Hz 调度时，发送端理论上需要处理 5200 个 CAN 帧/秒；实际到达率
需在使用的 USB-CAN 接口和 ROS 接收端测量。传感器的原始更新率可能低于遥测频率。

```text
621 [8] EB 90 05 C4 <timestamp 的 4 个小端字节>
```

后续 CAN 帧继续承载剩余字节，不重复发送应用层头部。

## 5. 接收端重组

1. 只接收标准 ID `0x621`。
2. 将每个 CAN 帧的数据段依次追加到接收缓冲区。
3. 在缓冲区中搜索 `EB 90`。
4. 读取消息 ID和载荷长度。
5. 等待接收完整的 `4 + N + 2` 字节。
6. 校验 CRC16，正确时解析载荷。
7. CRC 错误时丢弃当前消息，并搜索下一组 `EB 90`。

当前协议没有 CAN 分片序号。任意一帧丢失都会使本条消息 CRC 错误，接收端必须重新同步。

## 6. Jetson 基础测试

```bash
sudo ip link set can0 down
sudo ip link set can0 type can bitrate 1000000 restart-ms 100
sudo ip link set can0 up
candump can0,621:7FF
```

`candump` 只能确认原始 CAN 帧是否到达。要获得完整传感器样本，还需要实现字节流重组和 CRC 校验。
